# 0001. Record architecture decisions

- Status: accepted
- Date: 2026-10-19

## Context

Decisions made early, and the reasons behind them, are easily forgotten or accidentally undone, especially as new contributors join.

## Decision

Record each significant decision as a short numbered markdown file in `docs/adr/`, with the sections Status, Date, Context, Decision and Consequences. An accepted ADR is never edited to change its meaning; it is superseded by a new one.

## Consequences

A little writing per decision, and a permanent record of why the project looks the way it does.
